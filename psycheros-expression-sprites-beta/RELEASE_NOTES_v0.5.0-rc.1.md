# Expression Sprites Beta 0.5.0-rc.1

Rebased onto stock Psycheros 1.0.2 and its event-based agent loop. Streamed
directive filtering, final expression persistence, settings, chat display, and
voice overlay remain intact alongside upstream Flux and action UI behavior.

The guarded installer accepts only pristine 1.0.2 files or this identical
payload, creates timestamped backups, and refuses unknown local edits.
