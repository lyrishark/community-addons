# Loom Gemini Parser 0.5.0-rc.1

Rebased onto the Entity Loom shipped with Psycheros 1.0.2. Gemini remains an
explicit import platform for merged Thread Exporter batches, while the current
upstream wizard and parser registry behavior are preserved.

The guarded installer accepts only pristine 1.0.2 files or this identical
payload, creates timestamped backups, and refuses unknown local edits.
