# More Uploads 0.4.0-rc.1

- Revived the guarded source bridge after verifying that stock Psycheros 0.11.2
  still supports only one main-chat or typed-voice attachment at a time.
- Rebased the multi-attachment implementation on stock Psycheros 0.11.2 while
  preserving upstream Discord media and transient-vision behavior.
- Restored multi-select, paste, drag-and-drop, per-file previews and removal,
  document extraction, audio attachments, and Yin Yang typed attachments.
- Refreshed the exact-version guard, normalized stock-file hashes, browser cache
  key, cross-platform installers, and focused attachment tests.
