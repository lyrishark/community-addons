# More Uploads 0.5.0-rc.1

Rebased onto stock Psycheros 1.0.2. The bridge preserves the 1.0 action-drawer,
Flux, and multimodal-turn paths while restoring multiple attachments in ordinary
chat and Yin Yang typed mode. Native multimodal profiles receive bounded image
parts directly; non-multimodal routes retain caption fallback.

The guarded installer accepts only pristine 1.0.2 files or this identical
payload, creates timestamped backups, and refuses unknown local edits.
