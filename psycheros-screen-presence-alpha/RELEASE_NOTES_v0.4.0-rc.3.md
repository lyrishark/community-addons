# psycheros-screen-presence-alpha 0.4.0-rc.3

Compatibility refresh for Psycheros 0.11.3 (2026-09-22).

The guarded source bridge now targets **stock 0.11.3 only**. Upstream changes in overlapping files are retained; stock hashes and both installer variants (where provided) are refreshed.

Back up first and close Psycheros/Loom. Update or reinstall official source to a clean 0.11.3 tree before installing. Everything Together combines More Uploads, Expression Sprites, and Screen Presence; do not stack the individual bridges.
